# Свадбена покана — Мирослав & Марија (all phones)

Оваа верзија ја скалира целата покана според реалниот видлив viewport на телефонот преку `visualViewport`, па не се сече поради Safari/Chrome address bar.

Тестирајте ја во portrait на 320×568, 360×640, 375×667, 390×844, 393×852 и 430×932.

## GitHub Pages
1. Upload-ирај ги сите фајлови во root на repository.
2. `index.html` мора да биде директно во root.
3. Settings → Pages → Deploy from branch → `main` / `(root)`.
