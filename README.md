# Interactive Save-the-Date

A mobile-first, static wedding invitation inspired by the supplied Reel.

## Run locally
Open `index.html` in a browser. For best results, use a small local server (for example VS Code Live Server).

## Customize
Edit `index.html` to change:
- Names
- Date
- Location
- Invitation text

Edit colors in `style.css` under `:root`.

## Host on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)` and save.
6. GitHub will give you a public `github.io` URL.

This project is fully static, so GitHub Pages is enough. No backend is required.
